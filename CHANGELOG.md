# 2.1.0

- Обновлённые Twitch-токены сохраняются атомарно в отдельном файле с правами 0600. При перезапуске он имеет приоритет над первоначальными значениями окружения.
- OAuth-помощник обновляет и `.env`, и файл токенов.
- Compose сохраняет токены и SQLite в одном подключённом каталоге данных.
- Docker собирается из точных версий `requirements.lock`; добавлен `.dockerignore`.
- У панели нет IP и путей прежнего сервера по умолчанию; имя службы настраивается через `DASHBOARD_BOT_SERVICE`.
- Добавлен пример окружения панели, инструкции установки, обновления и отката.
- Старые архивы и отчёты исключены. Старые установщики оставлены только как тестовые фикстуры в `tests/legacy_ops`.
- Добавлены четыре проверки: перезапуск с обновлёнными токенами, отказ атомарной записи, начальные токены и повреждённое хранилище.

Крупные модули Telegram-меню и HTTP-маршрутизации не переписаны; выделен только самостоятельный модуль хранения токенов. Реальные Twitch/Telegram-соединения требуют пользовательских токенов.
