# Twitch Watcher — мониторинг по базе каналов


Telegram-бот для мониторинга сообщений в доступных Twitch-чатах и уведомления о совпадениях с отслеживаемыми логинами и ключевыми словами.

## Возможности

- Компактное inline-меню Telegram: эфиры, выбранные каналы, поиск фраз, активность, история и статистика.
- Пошаговое добавление и удаление с понятными подсказками и кнопкой отмены.
- Импорт собственного списка каналов из CSV в SQLite; чтение до 100 активных чатов только из этой базы.
- Уведомления об активности только по выбранным вручную каналам: начало и завершение эфира, смена названия или категории; проверка примерно раз в минуту.
- Поиск совпадений по автору сообщения и фразам; история сохраняется в SQLite.
- Автоматическое обновление Twitch access token через refresh token.
- Ограничение доступа к управлению по `TELEGRAM_ADMIN_ID`.
- Docker Compose и локальный OAuth-помощник Twitch.

## Важно о пределах Twitch

Это не сканер всех чатов Twitch. Бот ищет фразы в подключённых чатах. Уведомления об активности применяются только к каналам, добавленным владельцем вручную (до 100). Статус, название и категория берутся из Twitch Helix и проверяются раз в минуту.

Бот проверяет состояние всех импортированных каналов пакетами до 100 логинов. Если одновременно активны больше 100, читает первые 100 по возрастанию `rank` из CSV (при равном rank — по логину). После окончания эфира место освобождается при следующей проверке. Это не ротация всех чатов: сообщения в невыбранных чатах не читаются. Каналы вне базы не подключаются, даже если база пуста. Первый запуск со 100 чатами может занять около двух минут из-за ограничений Twitch на скорость подключения.

## Запуск локально

1. Установи Python 3.11+.
2. Скопируй `.env.example` в `.env` и заполни `TELEGRAM_BOT_TOKEN`, `TELEGRAM_ADMIN_ID`, `TWITCH_CLIENT_ID` и `TWITCH_CLIENT_SECRET`.
3. В Twitch Developer Console задай redirect URL `http://localhost:3000`.
4. Установи зависимости и получи Twitch user/refresh tokens:
   ```powershell
   python -m pip install -r requirements.txt
   python oauth_login.py
   ```
5. Импортируй CSV с колонкой `login` и необязательной колонкой `rank`, затем запусти бота:
    ```powershell
    python -m app.import_channels "channels.csv"
    python -m app.main
    ```
6. Открой Telegram-бота и отправь `/start`. Раздел «Каналы» задаёт только уведомления об эфирах и не заменяет импортированный список поиска.

Для полной замены каталога: `python -m app.import_channels "channels.csv" --replace`. История, правила, очередь и ручные каналы не удаляются. Некорректный или пустой CSV не заменяет существующий каталог. Новый список учитывается при следующем сканировании; для немедленного применения можно штатно перезапустить бота.

## Запуск через Docker

Docker Desktop должен быть установлен и запущен. После настройки `.env` выполни:

```powershell
docker compose build
docker compose run --rm -v "${PWD}/channels.csv:/tmp/channels.csv:ro" twitch-watcher python -m app.import_channels /tmp/channels.csv
docker compose up -d --build
docker compose logs -f
```

## Настройки `.env`

- `MONITOR_MAX_CHANNELS=100` — максимум читаемых активных чатов из базы, от 1 до 100.
- `MONITOR_REFRESH_SECONDS=60` — пауза между проверками после завершения сканирования, минимум 30 секунд.
- Старые переменные `AUTO_MONITOR_*` больше не используются. Глобальный подбор эфиров удалён.
- `DATABASE_PATH=./data/watcher.sqlite3` — файл истории и настроек.
- `TELEGRAM_PROXY` — необязательный HTTP-прокси для Telegram API.

## Управление ботом

Откройте главное меню командой `/start`, затем выбирайте нужное действие кнопками под сообщением. Для добавления отправьте значение только после выбора действия; незавершённый ввод можно отменить кнопкой «Отмена». Постоянная клавиатура у строки ввода открывает все разделы. Переход в раздел отменяет незавершённый ввод. Если клавиатура свёрнута, нажмите значок клавиатуры рядом со строкой ввода. Управление доступно владельцу бота.

## Состав папки

- `app/` — Telegram-бот, Twitch-мониторинг и работа с базой данных.
- `dashboard/` — отдельная веб-панель управления сервером.
- `oauth_login.py` — локальная авторизация Twitch.
- `requirements.txt`, `Dockerfile`, `compose.yaml` — зависимости и варианты запуска.
- `.env.example` — пример настроек без секретов.

Не публикуй `.env`: он содержит Telegram- и Twitch-секреты. В этой папке оставлена актуальная объединённая версия проекта.

## История совпадений

Раздел «История» и команда `/history` открывают записи по пять на странице. Можно совместить фильтры по каналу, фразе в причине совпадения и периоду: сегодня, последние 7/30 дней или конкретная дата по московскому времени. «Сбросить» очищает фильтры. CSV содержит последние 5000 записей по текущим условиям, время в файле указано в UTC. Фильтры действуют до перезапуска бота; сохранённая история остаётся в базе данных.

## Восстановление соединений и доставка

Чтение Twitch, обновление каналов и доставка Telegram выполняются независимо. Совпадение и уведомление сохраняются одной транзакцией SQLite. Очередь отправки переживает перезапуск; временные ошибки Telegram повторяются с задержкой до 30 секунд. При неоднозначном сетевом обрыве после отправки возможна повторная доставка. События Twitch во время отсутствия соединения не воспроизводятся.

Проверки: `python -m unittest discover -s tests -v`.

## Виды отслеживания

«Фразы» ищутся в активных чатах из импортированной базы (до 100 одновременно, по рейтингу CSV). «Пользователи» присылают сообщения выбранных авторов в чужих подключённых чатах независимо от ключевых слов. «Каналы» задают только уведомления о состоянии эфира и список «Эфиры»; отдельные подключения для чтения их чатов не резервируются. Для поиска сообщений автора нужен раздел «Пользователи».
